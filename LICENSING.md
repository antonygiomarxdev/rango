# Rango Licensing

This file explains how Rango licensing works in practice. It is a guide for humans.
The binding terms are in the root [LICENSE](LICENSE).

## Model

Rango is source-available under **Business Source License 1.1** with a project-specific
**Additional Use Grant**.

The goal is simple:

- let builders, research, open-source projects, and small teams use Rango freely
- require a paid commercial license from larger companies and monetized platform use
- require a paid commercial license for hosted, embedded, and competitive offerings

## Free to use without a separate commercial license

You can use Rango without a separate commercial license if your use fits the grant.
Typical examples:

- personal projects
- learning, evaluation, and research
- university and non-profit work
- open-source projects
- internal self-hosted use by organizations with fewer than 25 employees and less than USD 2,000,000 annual revenue
- non-commercial products distributed at no fee

## Uses that require a commercial license

A separate commercial license is required for any of the following:

- hosted or managed services offered to third parties
- SaaS, DBaaS, sync platform, or developer platform offerings built on Rango
- embedded commercial products or appliances distributed to customers
- organizations with 25 or more employees
- organizations with USD 2,000,000 or more annual revenue
- cloud providers, hyperscalers, platform providers, and managed service providers
- competitive offerings

## Quick matrix

| Scenario | Commercial license required? |
|---|---|
| Student prototype | No |
| Open-source library using Rango internally | No |
| Small startup using Rango for internal operations only | No, if below both thresholds |
| Internal deployment in a 200-person company | Yes |
| Paid SaaS product built on Rango | Yes |
| Hardware device sold with Rango embedded | Yes |
| Cloud provider exposing Rango-backed functionality | Yes |
| Competitive managed sync/database service | Yes |

## Why this model

Rango is intended to be easy to evaluate, hack on, and adopt for builders, while
protecting the project from being extracted into monetized infrastructure products
without participating in the economics of the project.

## Commercial licensing

If your use requires a commercial license, contact the repository owner through GitHub
before production deployment. The commercial agreement can cover hosted use, embedded
redistribution, OEM terms, support, and negotiated thresholds.
